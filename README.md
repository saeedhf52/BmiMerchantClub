# اکوسیستم شبکه تخفیف و باشگاه پذیرندگان

مستندات، طراحی مفهومی و ارائهٔ مدیریتی طرح اولیهٔ یک اکوسیستم تخفیف و بازاریابی دیجیتال برای شبکهٔ پذیرندگان کارتخوان.

## صفحهٔ معرفی عمومی

[ورود به landing page پروژه](https://saeedhf52.github.io/BmiMerchantClub/)

## معرفی طرح

این طرح، شبکهٔ کارتخوان را از یک رابطهٔ صرفاً فنی به یک پلتفرم رشد کسب‌وکار تبدیل می‌کند:

- پذیرنده، صفحهٔ اختصاصی و ابزار ساخت کمپین تخفیف دریافت می‌کند.
- مشتری، از داخل «بله» و بدون نصب اپلیکیشن جدید، تخفیف‌ها را کشف و با «QR» استفاده می‌کند.
- سازمان، به وفاداری پذیرندگان، دادهٔ رفتاری، کمپین‌های هدفمند و جریان‌های درآمدی جدید دست پیدا می‌کند.
